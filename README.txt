Tanmay Zile - Portfolio
=======================

OPEN IT
  Double-click index.html. It runs in any modern browser (needs internet
  for React and the font, which load from a CDN).

EDIT YOUR CONTENT
  Open index.html in VS Code and search for "const D=".
  Your intro, about text, skills, projects and certificates are all there.
  The page rebuilds from that object, so edit the text and save.

CHANGE COLOURS
  Search for ":root{" near the top. Change --cb (orange), --ink (black),
  --bg (page background), --lem and --sky (soft highlights).

PUT IT ONLINE (free)
  - Netlify: go to app.netlify.com/drop and drag the tanmay-portfolio folder in.
  - GitHub Pages: upload index.html to a repo, then Settings > Pages.
  - Vercel: import the folder or repo, no build settings needed.

ADD LINKEDIN / GITHUB
  Add the links in the contact section of index.html, or ask Claude to add them.
